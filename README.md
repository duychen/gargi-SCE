TraceGuard - Cybersecurity Awareness Project

ABOUT
TraceGuard is an educational project that demonstrates basic login security and account protection.

FEATURES
- Simulates login attempts
- Demonstrates account lockout after three failed attempts
- Displays a privacy notice
- Provides a simple dashboard

TECHNOLOGY
HTML, CSS, and JavaScript.

HOW TO RUN
1. Locate traceguard_cybersecurity_project.html.
2. Double-click the file.
3. It opens in a web browser.

SAFETY
This is an educational simulation. Do not enter real passwords or confidential information.
